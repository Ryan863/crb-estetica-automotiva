# CRB Estética Automotiva

Landing Page Oficial de Alto Padrão para **CRB Estética Automotiva** (@crbestetica_).

## 🚀 Tecnologias

- **Framework:** Next.js 16 (App Router) & React 19
- **Estilização:** Tailwind CSS & Vanilla CSS Variables
- **Animações:** GSAP & @gsap/react com ScrollTrigger
- **Ícones:** Lucide React (strokeWidth 1.8)
- **Componentes:** Padrões modernos inspirados no 21st.dev (Spotlight Cards, Glowing Borders)
- **SEO & Structured Data:** Schema.org LocalBusiness / AutoRepair

## 🛠️ Instalação e Execução

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Gerar build de produção
npm run build
```
